Конфигурации

Каталог

Конфигурации стоят карточками: имя, отклик сервера, метки - «MTU авто» или «MTU 1420», имя подписки, из которой конфигурация пришла, - и отметка «Выбран» у выбранной. Переключатель «Используется» выбирает конфигурацию для следующего подключения; ссылка «Подключиться» поднимает туннель на ней сразу, «Настройки» открывает её страницу, «Изменить порядок» в меню карточки переставляет карточки.

«Проверить» меряет отклик всех серверов разом, мимо туннеля. На карточке появляется время в миллисекундах, «нет ответа», «недоступен», если у сервера нет адреса, или «не видно из туннеля», если туннель поднят на другой конфигурации и уводит пробу в себя. У подключённого сервера на карточке стоит отклик самого туннеля. «Обновить конфиги» перечитывает все подписки сразу, не дожидаясь их срока. Когда подписка принесла новую версию конфигурации, а туннель работает на старой, главный экран пишет «Доступно обновление конфигурации»: она применится при следующем подключении.

Добавление конфигурации

«Добавить» в каталоге и «Добавить конфигурацию» на главном экране предлагают способ:

  • «Загрузить файл» - файл .conf или картинка с QR-кодом. Файл выбирается системным выбором файлов; на телевизоре и там, где его нет, - встроенным обозревателем: «Папка приложения», «Общее хранилище», а файлы вне папки приложения видны после «Разрешить доступ ко всем файлам…».
  • «Вставить» - из буфера обмена: текст конфигурации wg-quick, ссылка vpn:// или адрес подписки http(s). Адрес подписки приложение распознаёт само, читает его и загружает конфигурации, которые он отдаёт, а дальше держит их свежими, см. Автообновление подписок. Адрес без шифрования помечается предупреждением: ключи из подписки идут открытым текстом. Адрес, который отдаёт не панель AmneziaGeo, не добавляется: приложение отвечает «подписка … не от панели AmneziaGeo» и пишет предупреждение в журнал.
  • «Сканировать QR-код» - камерой, где она есть.
  • «Создать вручную» - редактор текста wg-quick; нужны секции [Interface] и [Peer].

Конфигурация с параметром, которого движок не знает, отклоняется с сообщением, что нужна более новая версия AmneziaWG. Общий файл настроек с другого устройства - конфигурации и списки маршрутизации вместе - импортируется через «Импорт / экспорт» в разделе Общие.

Настройки конфигурации

Страница конфигурации открывается ссылкой «Настройки» на карточке. «Имя конфигурации» - под ним у конфигурации из подписки стоит имя подписки, время последнего обновления и кнопка «Обновить», которая перечитывает подписку сейчас. «Текст конфигурации» скрыт за кнопкой «Показать»: это wg-quick, как он сохранён, только для чтения. Имя сохраняется кнопкой «Сохранить» внизу страницы. Ниже на той же странице стоят настройки транспорта, см. Транспорт.

Подписка выключенаСервер выключил свою подписку из-за сертификата: конфигурация работает, обновлений из подписки не будет. Когда сервер AmneziaGeo выключил свою подписку из-за сертификата, который берут не все клиенты, на карточке перед «Обновить» и у кнопки «Обновить» на странице конфигурации стоит значок «!», а «Обновить» не нажимается. Значок называет причину: у сервера нет сертификата, сертификат истёк, выдан не на то имя и другие; под именем конфигурации пишется «Подписка сервера выключена: <причина>». Конфигурация работает, а подписку приложение не читает, пока сервер не отдаст её снова.

Текст конфигурации, её DNS для имён, которые идут напрямую, и исключения меняются из консоли: amneziageo config edit <имя> ..., amneziageo config dns <имя> [<серверы>] и amneziageo config exclusions <имя> ...; новый текст туннель берёт при следующем подключении. На Android они не действуют: имена определяются внутри туннеля, а исключения задаются в списке маршрутизации.

Экспорт

«Экспорт» на странице конфигурации показывает QR-код в одном из видов: «QR файл» - содержимое .conf, «QR ссылка» - ссылка vpn://, «Подписка» - адрес подписки у конфигурации, которая из неё пришла. «Скопировать» кладёт текст в буфер обмена, «Скачать QR» сохраняет картинку, «Отправить…» передаёт в другое приложение. QR-код содержит приватный ключ: не показывайте его посторонним. Длинная конфигурация в QR-код не помещается, тогда остаётся текст или ссылка vpn://. Из консоли ссылку печатает amneziageo config link <имя>.

Удаление

«Удалить конфигурацию» внизу страницы спрашивает подтверждение; отменить удаление нельзя. Конфигурация из подписки вернётся при её обновлении, пока подписка её отдаёт; подписку целиком удаляет amneziageo sub remove <имя> --configs.

Транспорт

Настройки транспорта на странице конфигурации: «Прокси» (WebSocket, см. ниже), «MTU», «DNS», «IPv6», «Маршрутизация», «Удерживать трафик при обрыве туннеля», «Разрешить серверу отключать туннель».

  • «MTU» - размер пакета туннеля: «Авто» - наибольший, который проходит по каналу, но не больше объявленного в конфигурации, «Конфиг» - ровно из строки MTU конфигурации, «Вручную» - число от 1280 до 1500. Действующее значение стоит меткой на карточке. Из консоли: amneziageo config mtu <имя> auto|config|<число>.
  • «DNS» Только с сервером AmneziaGeoПункт «Сервер» спрашивает DNS-сервер панели AmneziaGeo внутри туннеля.Подробнее - у кого спрашиваются имена, которые идут через VPN: «По умолчанию» - что выбрал сервер AmneziaGeo этой конфигурации, иначе строка DNS её текста; «Сеть» - DNS сети устройства, мимо туннеля; «Сервер» - DNS-сервер самого сервера внутри туннеля, пункт доступен, когда сервер его даёт; выбор известен только этому клиенту, и когда DNS-сервер панели остановится (режим «Автоматически» без правил по именам), при следующем подключении имена идут как при «По умолчанию»; «Своё значение» - адреса из поля, хотя бы один IPv4, пустое поле - 1.1.1.1, 1.0.0.1. Поле рядом серым показывает, на чём стоит выбор. Берётся при следующем подключении. Из консоли: amneziageo config vpn-dns <имя> default|network|server|own [<серверы>].
  • «IPv6» - несёт ли туннель IPv6; по умолчанию выключено, см. Ограничения.
  • «Маршрутизация» Только с сервером AmneziaGeoСервер AmneziaGeo оставил этой конфигурации только свои списки маршрутизации.Подробнее - применять ли к этой конфигурации выбранный список маршрутизации. С выключенным переключателем туннель идёт по AllowedIPs из её текста. Из консоли: amneziageo config routing <имя> on|off. У конфигурации, чей сервер разрешает только свои списки, переключатель включён, недоступен и помечен значком AmneziaGeo, см. Что предлагает сервер.

WebSocket Только с сервером AmneziaGeoФронт WebSocket называет сам сервер AmneziaGeo: адрес и порт вводить не надо.Подробнее

AmneziaWG работает поверх UDP, а в некоторых сетях - корпоративный и гостевой Wi-Fi, часть мобильных операторов - он не проходит. Тогда весь туннель пускается поверх WebSocket по TCP: снаружи это выглядит как обычный HTTPS-трафик.

Сервер AmneziaGeo, который ответил, сам предлагает вход: хост Endpoint конфигурации и порт его сервисов. По умолчанию это порт Endpoint, а если сервер перенёс сервисы, то порт из строки # AmneziaGeo Services = <порт>. Вход набирается по TLS, сервер узнаёт конфигурацию по токену из её ключей, поэтому сертификат не проверяется. Если наш сервер вход не предлагает, переключатель WebSocket недоступен.

Старый сервер AmneziaGeo называет свой вход в выдаваемой конфигурации, строкой # AmneziaGeo WebSocket = wss://<хост>:<порт>/<путь>, и этот вход берётся как есть.

Для любого другого сервера вход задаётся в настройках: адрес и порт, а если сервер требует авторизацию, логин с паролем или токен. Пустые адрес и порт берутся из хоста и порта Endpoint; адрес или порт, который не годится, считается пустым. Такой вход набирается по TLS с проверкой сертификата. Включить WebSocket решаете вы. Из консоли: amneziageo config websocket <имя> on|off [--host <адрес>] [--port <порт>].

Удерживать трафик при обрыве туннеля

Пока туннель переподключается, выбранное не идёт напрямую. Как это действует - в разделе Удержание трафика при обрыве туннеля.

Разрешить серверу отключать туннель Только с сервером AmneziaGeoСервер AmneziaGeo снимает туннель этого устройства, когда клиента выключают в панели.Подробнее

Сервер снимает туннель, когда этого клиента выключают на сервере. Переключатель доступен, пока панель сервера AmneziaGeo этой конфигурации включила сигнал этому клиенту; с другим сервером или без сигнала он выключен и недоступен, а выбор, сделанный раньше, сохраняется. Как это действует - в разделе Удержание трафика при обрыве туннеля.

Роутер

На Android роутер встаёт, когда часть списка решается на лету - правило тяжелее половины порога (по умолчанию 11 000 записей) или то, что в порог не вошло, - или включён «Весь UDP через туннель»: тогда соединения проверяются по правилам, в том числе по приложению, и VPN видят все приложения. Остальное держит таблица маршрутов: адреса доменов определяются при подключении (сначала из прошлого раза, потом заново через туннель), а приложения из правил «Только выбранное» входят в сеть туннеля одни, см. Кто видит VPN. Переключателя в окне нет.

Что предлагает сервер

Приложение спрашивает сервер AmneziaGeo, что он предлагает конфигурации: при открытии окна, после добавления или правки конфигурации, когда подписка или набор принесли конфигурацию, чей сервер ещё не спрошен, и перед подключением. Первое подключение конфигурации и подключение после смены её Endpoint или ключей ждут ответа; следующие берут сохранённый ответ сразу, а наш сервер спрашивается снова фоном раз в сутки. Вопрос идёт по TCP на хост Endpoint и порт сервисов, приложение доказывает ключи конфигурации, и ответ зашифрован для неё одной.

Ответ хранится по конфигурации: вход WebSocket и где мерить скорость. Ещё ответ раздаёт гео-источники сервера и списки маршрутизации, которые назначены в шаблоне клиента. Приложение добавляет источник, если у него нет источника с таким адресом, переводит источник с тем же именем на адрес сервера, один раз на каждый адрес, и сразу скачивает эти источники; удалённый владельцем источник возвращается со следующим ответом.

Список сервера узнаётся по идентификатору. Если такого списка нет, он добавляется и выбирается сам, когда сервер пометил его включённым по умолчанию и не выбран ни один список. Если список есть, он остаётся как есть; когда сервер с тех пор его изменил, на карточке и у заголовка открытого списка появляется «Обновить», и нажатие заменяет имя, правила и переключатели трафика присланными, а выбран список или нет, не меняется. Удалённый владельцем список возвращается со следующим ответом.

Список, который сервер держит «Только чтение», на карточке и у заголовка открытого списка помечен «Только чтение». Его нельзя переименовать, править и удалить ни в окне, ни из консоли («Список «…» только для чтения: он пришёл с сервера …»); включать и выключать его можно. Новая версия сервера ложится сама, без «Обновить», и открытый список перечитывается. Сервер снял флаг - список снова правится, а новая версия ждёт «Обновить»; сервер вернул флаг - список, который правили, берёт версию сервера; сервер перестал отдавать список - он остаётся обычным.

Сервер, который разрешает конфигурации только свои списки («Только списки сервера» в шаблоне клиента), ограничивает выбор, пока она подключена. При подключении свой список в работе или «без списка» сменяется списком сервера с пометкой «по умолчанию», иначе первым, и включается переключатель «Маршрутизация» конфигурации. Пока она подключена, «Используется» у других списков и у включённого списка сервера недоступен, как и тумблер маршрутизации на главном экране, а подсказка называет конфигурацию: «Сервер конфигурации … разрешает только свои списки маршрутизации». Из консоли выбор своего списка и none отказывают тем же текстом, routing list называет разрешённые списки. Флаг сняли или конфигурацию отключили - выбор списка снова свободный, включённый список остаётся.

Переключатель «Маршрутизация» на странице конфигурации заперт дольше: пока сервер держит флаг, он включён и недоступен с той же подсказкой, подключена конфигурация или нет, а config routing <имя> off отказывает тем же текстом. Флаг сняли - переключатель снова доступен.

На карточке списка написано, откуда он: имя конфигурации, с которой он пришёл, и перед ним значок Только с сервером AmneziaGeoСписок пришёл с сервера AmneziaGeo конфигурации, названной на карточке, новые версии приходят с него же.Подробнее, или «Локальный» у списка, созданного на устройстве. Списки сервера старше идентификаторов добавляются по имени и сами не выбираются.

Сервер другого вида или молчащий сервер ничего не меняет. Наш сервер остаётся нашим, пока трижды подряд не ответит как сервер другого вида или один раз при обновлении подписки; порт, который отказывает в соединении, считается таким ответом. Вопрос без ответа (время вышло, имя не нашлось, TLS не сошёлся, ошибка сервера) ничего не меняет, и сервер спрашивается снова после паузы, которая растёт вдвое от минуты до суток. Сервер, который на прошлый вопрос ответил как сервер другого вида, перед подключением спрашивается фоном, и подключение его не ждёт. Сервер, который ещё ни разу не ответил, сервером другого вида не считается: три следующих подключения ждут его снова, не дольше трёх секунд каждое, а дальше он тоже спрашивается фоном.

Вопрос и чтение подписки уходят по сети под туннелем, поэтому туннель, который стоит в наборе, их не глотает; пока туннель набирается через WebSocket, его сервер спрашивается снова с каждой попыткой, и когда ответ называет другой вход, чем тот, что набирает туннель, туннель набирается заново на него.

Подписка, прочитанная по адресу, доказывается сертификатом её сервера: по хранилищу устройства или по корням Let’s Encrypt, которые приложение несёт с собой для устройства, в чьём хранилище их нет.

Сервер со стороны панели описан в его репозитории: amneziageo_server.

Значок AmneziaGeo

Синий круг со знаком питания стоит у того, что работает только с сервером AmneziaGeo:

  • «Прокси»: вход WebSocket называет сам сервер, см. WebSocket;
  • «DNS»: пункт «Сервер», см. Транспорт;
  • «Маршрутизация», пока сервер оставил конфигурации только свои списки;
  • «Разрешить серверу отключать туннель», см. Разрешить серверу отключать туннель;
  • карточка списка, который пришёл с сервера: значок стоит перед именем конфигурации, см. Карточка списка;
  • «Сервис для проверки скорости передачи данных», см. Настройки пробы.

Нажатие на значок открывает шторку: что даёт сервер AmneziaGeo и как обстоит дело у этой конфигурации - её сервер AmneziaGeo с этой возможностью, сервер AmneziaGeo без неё или сервер не AmneziaGeo либо ещё не ответил. Нажатие на значок не трогает переключатель рядом.

На страницах этого сайта значок стоит у тех же настроек и открывает окно с тем же текстом. Панель сервера ставит тот же знак у того, что доходит только до приложения AmneziaGeo, см. Значок AmneziaGeo на сайте сервера.
