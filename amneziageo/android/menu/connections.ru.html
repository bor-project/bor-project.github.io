Подключения

Сервер обновлений

Строка вверху страницы - «Сервер обновлений»: откуда приложение берёт новые версии. В списке:

  • «Откуда установлено (<хост>)» - откуда пришла установленная версия: GitHub или сервер обновлений, с которого она поставлена;
  • серверы обновлений, которые предлагают серверы включённых конфигураций: «<хост> «<конфигурация>»», с пометкой «(рекомендован)», если сервер предлагает его по умолчанию.

Сервер обновлений предлагает сервер AmneziaGeo, в панели которого включены «Обновления клиентов». Пока выбор не сделан рукой, проверяется рекомендованный сервер, а без него - «Откуда установлено». Выбор рукой держится, пока сервер есть в списке: если он перестал раздавать обновления, проверка возвращается к «Откуда установлено». Проверяется только выбранный источник, на канале из «Общих»; версия ниже установленной не предлагается. Файлы с сервера обновлений берутся под сертификатом, которому верит система, или под тем, который назвал сервер. Патчи берутся только у источника, откуда установлено приложение; у другого оно качает установщик целиком. После обновления с сервера «Откуда установлено» называет этот сервер.

Если проверка не удалась, под строкой стоит причина, а у состояния на главном экране - знак:

Сообщение Что значит
Сервер обновлений <хост> не отвечает сервер недоступен или оборвал соединение
На сервере обновлений <хост> нет выпуска канала в выбранном канале у сервера нет выпусков
Сертификат сервера обновлений <хост> не тот, что назвал сервер сертификату не верит система, и это не тот, что назвал сервер
Сервер <хост> больше не раздаёт обновления, они берутся оттуда, откуда установлено приложение выбранный рукой сервер ушёл из списка

Сбои GitHub в эту строку не попадают. Из консоли: amneziageo settings set update-source origin|auto|<адрес> (auto снимает выбор рукой), в amneziageo status - источник, канал и ошибка.

Прокси

Приложение поднимает SOCKS5- и HTTP-прокси, через которые в туннель ходят устройства без своего клиента: телевизор, телефон, приставка.

  • «Разрешить подключения» включает прокси: им пользуются программы на этом компьютере и устройства локальной сети.
  • Порты задаются отдельно: «Порт SOCKS5» и «Порт HTTP». Адрес, по которому прокси доступен в сети, стоит рядом, кнопка копирует его.
  • Доступ - по «Учётным записям» («Пользователь» и «Пароль», подходит любая из них) либо через «Подключение без пароля»: тогда прокси открыт любому устройству в сети. Без учётной записи и без этого переключателя подключиться не сможет никто.
  • «Клиенты» показывает, кто подключён и сколько соединений держит.

В списке адресов стоит и адрес телефона в сети, которую он раздаёт сам: точка доступа Wi-Fi, USB-модем, Bluetooth («Раздача этого телефона»). Устройству, подключённому к раздаче, этот адрес и порт HTTP вписывают как прокси в настройках его сети Wi-Fi: без root Android не пускает трафик раздачи в VPN, а через прокси он идёт в туннель. Адреса мобильной сети в списке нет: соседей в ней нет.

Прокси из настроек сети слушаются браузер и программы, которые ходят в сеть через систему. Telegram на телефоне к ним не относится: адрес телефона и порт SOCKS5 вписывают в самом Telegram («Настройки» - «Данные и память» - «Настройки прокси», тип SOCKS5). Прокси несёт соединения TCP; датаграммы (UDP) соседних устройств через него не идут.

Трафик уходит в туннель только при поднятом туннеле.

Пошагово - в рецепте Устройства в сети через прокси. Из консоли: amneziageo proxy show, amneziageo proxy on [--socks <порт>] [--http <порт>] [--anon on|off] [--auth <пользователь:пароль>]... [--auth off], amneziageo proxy off.

Автообновление подписок

Конфигурации из подписок обновляются сами: агент перечитывает подписки раз в 12 часов, если панель не задала свой срок, а изменённая в панели конфигурация применяется при следующем подключении. Отдельной настройки в окне нет. Обновить все подписки сейчас - кнопка «Обновить конфиги» в каталоге конфигураций. Из консоли: amneziageo settings set subscription-auto-refresh-enabled on|off включает и выключает обновление, amneziageo settings set subscription-refresh-interval-hours <1-168> задаёт срок в часах; подписки ведут amneziageo sub list, amneziageo sub add <url> [<имя>], amneziageo sub refresh [<имя>], amneziageo sub remove <имя> [--configs].
