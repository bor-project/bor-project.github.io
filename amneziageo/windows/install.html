Installation

You need Windows 7, 10 or 11 (x64 or arm64) and administrator rights: the installer sets up a system service.

  1. Download the installer for your architecture from the Releases page. The regular build carries everything it needs; the smaller variant (-fdd) requires the .NET 10 Desktop Runtime already installed. The x64 installer does install on an ARM64 computer, but the tunnel will not work there; the installer warns about it.
  2. Run it. If you have not accepted this version of the terms yet, an installation or an update in the window opens with the terms of use and the privacy notes, on two tabs, with the version of the terms under them: “Accept” goes on to the options, “Quit” closes the installer and changes nothing. The app does not show terms accepted here a second time. A quiet install (/quiet) and an update from the app go without this page: the first start of the app shows a new version of the terms. “Installation options”: “Desktop shortcut”, “Start menu shortcut”, “Download geo database updates” - fetch the geo databases that are missing or out of date, “Launch AmneziaGeo after install” and “Connect on launch”. The agent service and the application are installed: the files go to Program Files\AmneziaGeo, the data to ProgramData\AmneziaGeo.

Next: first configuration.

Running the installer again over the installed version offers “Update”, “Repair” or “Remove”; the “Reset settings” box then wipes the configurations and the data, see Uninstalling. An earlier version is installed as a rollback: the installer removes the installed one first, then installs its own.

SmartScreen and Smart App Control

The installer and the files of the application are not signed yet: the work on getting a certificate is under way. Until then SmartScreen warns about an unknown publisher and Smart App Control on Windows 11 may block the launch. What to do about it: code signing policy.

Update

The app updates itself: it offers the new version and, when the installed copy is the release before it, fetches one patch with the files that changed against that copy, a changed file as a delta from the installed one, and runs the installer on them; from an older version, or where the patch does not fit, it downloads the whole installer for its own architecture. A download that broke off carries on from where it stopped. The buttons are in the General section.

Uninstalling

It is removed from Windows “Apps” (“Add or remove programs”) or by running the installer again and pressing “Remove”. The agent service is stopped and taken away, and the application in Program Files\AmneziaGeo, the shortcuts and the temporary tunnel services are removed. The data - the state database, the configurations, the geo databases and the logs in ProgramData\AmneziaGeo - stays so that a new installation picks it up; the “Delete configuration and cache” box in the removal options wipes it too.
