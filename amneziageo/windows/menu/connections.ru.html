Подключения

Туннель

  • «Показывать оповещения» - сообщения в трее о подключении, обновлениях приложения и баз.
  • «Восстанавливать после перезагрузки» - подключать выбранную конфигурацию при включении компьютера; в консоли это survive-reboot.
  • «Переподключаться автоматически» и «Интервал повтора» - после обрыва повторять попытки: сразу, через 5, 10 и 20 с, дальше через интервал; интервал - наибольшая пауза между попытками. Как идёт повтор - в разделе Переподключение.
  • «Не мешать другим VPN» - подключение SSTP, L2TP, PPTP или IKEv2 встроенного клиента Windows (а по описанию адаптера - Cisco, Fortinet, OpenVPN, GlobalProtect) рядом с туннелем работает как обычно: его адаптер пропускается защитой от утечек, сети, которые ведёт оно, остаются за ним, адрес сервера из подключения Windows идёт мимо туннеля, а имена с суффиксом подключения спрашиваются у его DNS. Выключите, если защита от утечек должна резать всё, кроме туннеля. Действует со следующего подключения; в консоли это other-vpn.
  • «Сервер обновлений» - откуда брать новые версии приложения, см. Сервер обновлений.
  • «Разрешить несколько VPN» включает режим из рецепта Несколько VPN одновременно. Под ним настройки перехода правил между серверами: «Интервал проверки» - как часто проверять, не стоит ли перевести правило на другой сервер, «Проверок перед переключением» - после скольких проверок без ответа подряд правило переходит на другой сервер, «Порог переключения» - насколько быстрее должен отвечать другой сервер, чтобы правило перешло на него.

Сервер обновлений

На вкладке «Туннель» строка «Сервер обновлений»: откуда приложение берёт новые версии. В списке:

  • «По умолчанию» - откуда получено последнее обновление, а до первого обновления - откуда установлено приложение: GitHub или сервер обновлений; под строкой его адрес;
  • адреса серверов обновлений, которые предлагают серверы включённых конфигураций.

Сервер обновлений предлагает сервер AmneziaGeo, в панели которого включены «Обновления клиентов». Пока выбор не сделан рукой, проверяется сервер, у которого в панели стоит «Включён по умолчанию», а без него - «По умолчанию». Выбор рукой держится, пока сервер есть в списке: если он перестал раздавать обновления, проверка возвращается к «По умолчанию». Проверяется только выбранный источник, на канале из «Общих»; версия ниже установленной не предлагается. Файлы с сервера обновлений берутся под сертификатом, которому верит система, или под тем, который назвал сервер. Патчи берутся только у источника, откуда установлено приложение; у другого оно качает установщик целиком. После обновления с сервера «По умолчанию» становится этот сервер.

Если проверка не удалась, под строкой стоит причина, а у состояния на главном экране - знак:

Сообщение Что значит
Сервер обновлений <хост> не отвечает сервер недоступен или оборвал соединение
На сервере обновлений <хост> нет выпуска канала в выбранном канале у сервера нет выпусков
Сертификат сервера обновлений <хост> не тот, что назвал сервер сертификату не верит система, и это не тот, что назвал сервер
Сервер <хост> больше не раздаёт обновления, они берутся оттуда, откуда установлено приложение выбранный рукой сервер ушёл из списка

Сбои GitHub в эту строку не попадают. Из консоли: amneziageo settings set update-source origin|auto|<адрес> (auto снимает выбор рукой), в amneziageo status - источник, канал и ошибка.

Прокси

Приложение поднимает SOCKS5- и HTTP-прокси, через которые в туннель ходят устройства без своего клиента: телевизор, телефон, приставка.

  • «Разрешить подключения» включает прокси: им пользуются программы на этом компьютере и устройства локальной сети.
  • Порты задаются отдельно: «Порт SOCKS5» и «Порт HTTP». Адрес, по которому прокси доступен в сети, стоит рядом, кнопка копирует его.
  • Доступ - по «Учётным записям» («Пользователь» и «Пароль», подходит любая из них) либо через «Подключение без пароля»: тогда прокси открыт любому устройству в сети. Без учётной записи и без этого переключателя подключиться не сможет никто.
  • «Клиенты» показывает, кто подключён и сколько соединений держит.

Прокси из настроек сети слушаются браузер и программы, которые ходят в сеть через систему. Telegram на телефоне к ним не относится: адрес телефона и порт SOCKS5 вписывают в самом Telegram («Настройки» - «Данные и память» - «Настройки прокси», тип SOCKS5). Прокси несёт соединения TCP; датаграммы (UDP) соседних устройств через него не идут.

Трафик уходит в туннель только при поднятом туннеле.

Пошагово - в рецепте Устройства в сети через прокси. Из консоли: amneziageo proxy show, amneziageo proxy on [--socks <порт>] [--http <порт>] [--anon on|off] [--auth <пользователь:пароль>]... [--auth off], amneziageo proxy off.

Точка доступа

Вкладка «Wi-Fi». «Точка доступа» включает раздачу: компьютер раздаёт Wi-Fi, а подключённые устройства выходят в интернет через него - при поднятом туннеле по его правилам, то есть в туннель уходит то же, что и у самого компьютера, без туннеля напрямую. «Имя сети» - до 32 байт, «Пароль» - от 8 до 63 символов, кнопка рядом показывает его. «Диапазон» - «Авто», «2,4 ГГц» или «5 ГГц»; если адаптер выбрал частоту сам, под полем написано, на какой сеть работает. «Устройства» перечисляет подключённых. Точка доступа стоит на своём переключателе, отдельно от прокси.

Раздача идёт через службу Windows «Общий доступ к подключению к Интернету»: если она остановлена, вкладка говорит об этом. Нужен адаптер Wi-Fi, который умеет раздавать.

Пошагово - в рецепте Раздача VPN по Wi-Fi. Из консоли: amneziageo hotspot show, amneziageo hotspot on [--ssid <имя>] [--password <пароль>] [--band auto|2.4|5] [--hidden on|off], amneziageo hotspot off.

Автообновление подписок

Конфигурации из подписок обновляются сами: агент перечитывает подписки раз в 12 часов, если панель не задала свой срок, а изменённая в панели конфигурация применяется при следующем подключении. Отдельной настройки в окне нет. Обновить все подписки сейчас - кнопка «Обновить конфиги» в каталоге конфигураций. Из консоли: amneziageo settings set subscription-auto-refresh-enabled on|off включает и выключает обновление, amneziageo settings set subscription-refresh-interval-hours <1-168> задаёт срок в часах; подписки ведут amneziageo sub list, amneziageo sub add <url> [<имя>], amneziageo sub refresh [<имя>], amneziageo sub remove <имя> [--configs].
