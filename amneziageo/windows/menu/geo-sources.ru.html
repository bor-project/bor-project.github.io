Источники geo

Базы для правил geosite: - категории доменов - и geoip: - страны и сети. Раздел открывается ссылкой из маршрутизации.

Базы по умолчанию

Свежая установка получает источники сама: Loyalsoldier/v2ray-rules-dat (geosite и geoip), runetfreedom (geosite-ru-only и geoip-ru-only), zkeen-ip (geoip) и собственные базы проекта amneziageo-geo (geoip и geosite; их ключи начинаются с ag-, так что они не перекрывают ключи других баз). Копии баз runetfreedom лежат в комплекте приложения, поэтому правила по ним работают до первой загрузки. Остальные базы скачиваются по «Обновить все» или по кнопке «Обновить сейчас» на главном экране, когда проверка нашла, чего не хватает; установщик Windows предлагает скачать их во время установки. Источник, добавленный в набор по умолчанию позже, появляется при обновлении приложения; удалённый вами не возвращается.

Список баз

Каждая база - строка: имя, тип, число категорий и время загрузки, «не загружен» или «ошибка», если файла нет, во время загрузки - принятые мегабайты. Базы одного типа складываются по порядку: категория берётся из последней базы в списке, в которой она есть, поэтому своя база дополняет общие, а не заменяет их. Правый клик или ⋮ у строки: «Обновить», «Изменить» адрес или тип, «Удалить». «Обновить все» скачивает заново базы, чьи файлы изменились: сервер спрашивается с ETag и датой файла, неизменившийся файл не качается.

Добавить базу

Вставьте прямую ссылку на файл geosite.dat или geoip.dat и нажмите «Добавить». Тип определяется по имени файла в ссылке, если в нём есть geosite или geoip, иначе выберите его сами. Нужна ссылка на сам файл (raw), а не на страницу репозитория: страница не разбирается как база, и приложение скажет об этом. Добавленная база скачивается сразу.

Автообновление

Переключатель «Автообновление» раз в сутки проверяет, не вышли ли новые версии баз, без скачивания: по опубликованной рядом с файлом контрольной сумме .sha256sum, а где её нет - по заголовкам и размеру файла. База с новой версией помечается «Доступно обновление», а на главном экране появляется «Доступны обновления geo-списков»: «Обновить сейчас» скачивает их, «Позже» убирает полосу до следующей проверки. Включено по умолчанию.

Сервер AmneziaGeo присылает свои источники вместе с ответом конфигурации, см. Что предлагает сервер.

Из консоли

amneziageo source list
amneziageo source add geosite|geoip <url>
amneziageo source edit <имя> geosite|geoip <url>
amneziageo source remove <имя>
amneziageo geo list --filter telegram   # категории загруженных баз
amneziageo geo show geosite:telegram    # что входит в категорию
amneziageo geo check                    # есть ли новые версии, без скачивания
amneziageo geo update [<источник>]      # скачать заново
amneziageo geo download                 # добавить источники по умолчанию и скачать их
