Connections

Proxy

The application runs SOCKS5 and HTTP proxies through which devices without a client of their own reach the tunnel: a TV, a phone, a console.

  • “Allow connections” turns the proxy on: programs on this computer and devices on the local network use it.
  • The ports are set separately: “SOCKS5 port” and “HTTP port”. The address at which the proxy is reachable on the network stands beside them, and a button copies it.
  • Access is by “Accounts” (“User” and “Password”, any of them will do) or through “Connect without a password”: then the proxy is open to any device on the network. With no account and without that switch nobody can connect.
  • “Clients” shows who is connected and how many connections each holds.

A proxy set in the network settings is followed by the browser and by programs that reach the network through the system. Telegram on a phone is not one of them: the phone’s address and the SOCKS5 port go into Telegram itself (Settings - Data and Storage - Proxy Settings, type SOCKS5). The proxy carries TCP connections; datagrams (UDP) of neighbouring devices do not pass through it.

Traffic reaches the tunnel only while the tunnel is up.

Step by step: the Devices on the network through the proxy recipe. From the console: amneziageo proxy show, amneziageo proxy on [--socks <port>] [--http <port>] [--anon on|off] [--auth <user:password>]... [--auth off], amneziageo proxy off.

Access point

The “Wi-Fi” tab. “Access point” turns sharing on: the computer shares Wi-Fi, and the devices joined to it reach the internet through it - with the tunnel up by its rules, so the same goes into the tunnel as for the computer itself, and without the tunnel directly. “Network name” - up to 32 bytes, “Password” - from 8 to 63 characters, and the button beside it shows it. “Band” - “Auto”, “2.4 GHz” or “5 GHz”; when the adapter picked the band itself, the line under the field says which one the network runs on. “Hidden network” takes the name off the air. “Devices” lists the ones joined. The access point has a switch of its own, apart from the proxy.

The packages hostapd, dnsmasq and iw and a Wi-Fi adapter that can work as an access point are needed; without them the tab names what is missing.

Step by step: the Sharing the VPN over Wi-Fi recipe. From the console: amneziageo hotspot show, amneziageo hotspot on [--ssid <name>] [--password <password>] [--band auto|2.4|5] [--hidden on|off], amneziageo hotspot off.

Subscription auto-refresh

Configurations from subscriptions refresh themselves: the agent reads the subscriptions again every 12 hours unless the panel set a term of its own, and a configuration changed in the panel applies at the next connect. There is no separate setting in the window. To refresh every subscription now, use the “Refresh configs” button in the configuration catalogue. From the console: amneziageo settings set subscription-auto-refresh-enabled on|off turns refreshing on and off, amneziageo settings set subscription-refresh-interval-hours <1-168> sets the term in hours; subscriptions are managed with amneziageo sub list, amneziageo sub add <url> [<name>], amneziageo sub refresh [<name>], amneziageo sub remove <name> [--configs].
