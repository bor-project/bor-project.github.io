Командная строка

Основной набор команд общий для всех трёх платформ: сборка AmneziaGeo.Cli, а поверх неё тонкий хост под каждую систему. Его дополняют команды отдельных платформ, например режим нескольких VPN на Windows. Всё идёт через агента по протоколу IpcContract, базу консоль не трогает - поэтому её правки сразу видят и агент, и интерфейс.

Запуск

amneziageo <команда>

Повседневное

amneziageo status                   # что работает и что возьмёт следующее подключение
amneziageo doctor                   # проверки, на которых обычно спотыкается установка
amneziageo runtime                  # конфигурация, которую возьмёт следующее подключение
amneziageo --json config list       # вывод для скриптов
amneziageo sessions --filter youtube # каждый адрес, который решает туннель, и почему
amneziageo log tail --level info
amneziageo tui                      # полноэкранная консоль по SSH

amneziageo help перечисляет все команды.

Справочник команд

Глобальные ключи стоят перед командой: --json - JSON вместо таблиц, --lang en|ru - язык вывода (иначе AMNEZIAGEO_LANG, иначе язык системы), --timeout <с> - сколько ждать ответа (загрузка баз требует больше), --quiet - только запрошенное, --version - версии клиента и агента, --help.

Списки маршрутизации

Команда Что делает
routing list списки; READ-ONLY yes у списка, который сервер держит «Только чтение»: его команды правки и удаления отклоняют; строка под таблицей называет разрешённые списки, пока подключена конфигурация, чей сервер разрешает только свои
routing use <id|имя|none> выбрать список; none оставляет решение за AllowedIPs конфигурации
routing show <id|имя> правила списка; у app:<имя> - что нашло устройство: -> <путь или пакет>, -> not found, -> searching
routing create <имя> [правило...] создать
routing set <id|имя> [правило...] заменить все правила
routing add <id|имя> <правило...> добавить; правило, которое уже есть, получает новую роль
routing delete-rule <id|имя> <правило...> удалить правила
routing remove <id|имя> удалить список
routing update <id|имя> взять новую версию списка, которую прислал его сервер
routing order <имя> [<имя>...] порядок в разделе
routing settings <id|имя> настройки трафика
routing configure <id|имя> [--exclusions <a,b>] [--exclusions-file <путь>] [--all-udp on|off] [--global-proxy on|off] исключения, весь UDP через туннель, полный туннель

Правило - <роль>|<запись>: роль proxy, direct или block, запись geosite:<категория>, geoip:<страна>, domain:<имя>, app:<id> или app:<имя программы> либо адрес или диапазон CIDR. Запись без роли считается proxy.

subscription-auto-refresh-enabled on или off: перечитывать подписки по таймеру

update-channel stable, beta или test: канал обновлений

Служба

start запускает агента, stop останавливает его и опускает туннель, daemon status говорит, работает ли он, стоит ли в автозагрузке и есть ли сокет; daemon install [--data <каталог>] [--iface <имя>] [--engine <путь>], daemon uninstall, daemon restart и daemon logs [--follow] обслуживают юнит systemd. Подробнее - в разделе Запуск и остановка установки.

Полноэкранная консоль

amneziageo tui - полноэкранный интерфейс консольного клиента, в том числе по SSH. Слева рейка разделов, справа панель раздела.

  • «Состояние»: туннель подключён или отключён, выбранная конфигурация, список маршрутизации, последняя ошибка; кнопки «Подключить», «Отключить», «Обновить».
  • «Конфигурации»: «Выбрать», «Показать» текст, «Импорт» - одно поле на конфигурацию wg-quick, ссылку vpn:// или адрес http(s), который агент читает как подписку, «Ссылка» - ссылка vpn:// конфигурации, «Удалить».
  • «Маршрутизация»: «Выбрать» список, «Отключить» маршрутизацию, «Правила…» - редактор, одно правило в строке: proxy|geosite:x, direct|geoip:ru, block|domain:y, «Параметры…» - «Весь UDP через туннель» и исключения, «Удалить».
  • «Источники geo»: «Обновить все» и удаление базы.
  • «Общие»: уровень журнала, «Восстанавливать после перезагрузки», «Переподключаться автоматически», «Интервал повтора», «Записывать подключения в журнал».
  • «Диагностика»: журнал агента с поиском и очисткой.

Клавиши: стрелки или Tab - переход между панелями и элементами, Enter - нажать, F10 - выход; Esc консоль не закрывает. Ctrl+V вставляет из буфера обмена через wl-paste, xclip или xsel; без них вставляйте сочетанием самого терминала, Ctrl+Shift+V.

Отладка

amneziageo log say "начало прогона" # отметка в журнале агента
amneziageo ops                      # операции протокола и команды, которые их вызывают
amneziageo ops --probe              # какие операции реализует агент этой платформы
amneziageo ipc <операция> [арг...]  # вызвать любую операцию напрямую

ops --probe шлёт каждую операцию без аргументов: отказ от её обработчика значит, что операция есть, а отказ диспетчера - что её нет. Операции, которые без аргументов сделали бы работу по-настоящему - подключение, скачивание, удаление, - помечаются - и не отправляются.

Переменные окружения: AMNEZIAGEO_LANG - язык вывода без --lang, AMNEZIAGEO_CONNECT_WAIT - сколько секунд ждать агента (по умолчанию 5).
