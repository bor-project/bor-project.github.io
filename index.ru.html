AmneziaGeo

Клиент AmneziaGeo поднимает туннели AmneziaWG на Windows, Linux и Android и по правилам решает, что идёт через них. Сервер AmneziaGeo - панель своего сервера AmneziaWG: выдаёт клиентам конфигурации и направляет их трафик дальше по тем же правилам.

  • AmneziaGeo VPN-клиент для Windows, Linux и Android на движке AmneziaWG. Маршрутизация по гео-базам, доменам, диапазонам адресов и приложениям; несколько VPN одновременно на Windows. Windows · Linux · Android
  • AmneziaGeo Server Панель управления своим сервером AmneziaWG на Debian и Ubuntu - клиенты, шаблоны и подписки, маршрутизация по гео-базам и доменам через другие серверы, резолвер для клиентов, обновления и резервные копии. Служба · Docker
