Рецепты

Готовые сценарии: что нажать в панели и что проверить. Имена серверов, адреса и клиенты в примерах выдуманные.

  • Выход через другой сервер Канал AmneziaWG к другому серверу и правило по странам и сайтам.
  • Группа каналов с резервом Несколько каналов под одним именем: приоритет, по кругу, по клиенту.
  • Туннель внутри WebSocket Для сетей, где проходит только веб-трафик.
  • Подписка на несколько устройств Одна подписка для всех устройств одного человека.
  • Доступ к устройству за клиентом Достать клиента из туннеля: только сервер или вся сеть.
  • Маршрутизация на устройстве клиента Пресеты и гео-источники для приложения AmneziaGeo через шаблон.
  • Перенос на другой сервер Резервная копия базы и установка на новом хосте из неё.
