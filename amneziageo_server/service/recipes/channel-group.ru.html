Группа каналов с резервом

Задача: трафик правила уходит через один из нескольких серверов, и когда один падает, правило само переходит на другой. Несколько каналов собираются в группу, а правило называет группу.

1. Каналы

Заведите два и больше каналов, как в рецепте Выход через другой сервер, например awg-de и awg-nl, каждый со своей проверкой доступности: сервер имён и период. Без проверки канал считается живым по возрасту рукопожатия, с ней - по ответу на вопрос через туннель, и два промаха подряд снимают канал с группы, один ответ возвращает.

2. Группа

«Маршрутизация» > «Каналы» > «Группы» > «Добавить»:

  1. «Название» europe; имя не может совпасть с именем канала.
  2. «Стратегия»:
    • «Приоритет» - первый живой канал списка, при его молчании следующий; основной и резервный;
    • «По кругу» - новые соединения по живым каналам по очереди; распределение нагрузки;
    • «По клиенту» - канал по адресу клиента: один клиент держится одного канала, пока набор живых не изменился; для сервисов, которым важно, чтобы сессии одного человека шли с одного адреса.
  3. «Каналы»: awg-de, awg-nl в порядке выбора.
  4. «Включено», «Сохранить».

В списке группы живые члены отмечены «на хосте».

3. Правило

В правиле «Через канал» выберите в поле «Канал» группу europe; в списке правил такой канал отмечен «группа». Когда ни один член не несёт, трафик правила отбрасывается.

Что происходит при отказе

Группа читает живых членов каждые пятнадцать секунд, и когда набор меняется, набор правил ложится на хост заново: трафик правила переходит на следующий канал без участия человека. Соединение, открытое через упавший канал, не переезжает: решение принято на его первом пакете, клиент открывает новое. Когда ни один член не несёт, правило показывает «трафик заперт» с «Ни один канал не отвечает». Изменение в панели круга не ждёт: выключенный или убранный из группы канал уходит из набора сразу.

DNS-сервер тоже может спрашивать через группу: на странице DNS «Запросы к ним» - «Через канал», в поле «Канал» - группа; группа «Приоритет» отдаёт вопросы первому живому члену, «По кругу» раздаёт их по очереди.

Проверка

«Маршрутизация» > «Проверка» с именем из правила показывает «Через канал europe» и члены группы с отметками «несёт», «в резерве», «недоступен», «выключен» и тем, какой выбран. Опустите один канал (выключите его переключателем) и повторите: выбран другой член.
