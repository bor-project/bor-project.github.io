Your server and your clients

You install the server and keep it. The traffic of your clients goes through it, and you see which addresses they reach and when. You answer for:

  • access to the server and the panel, passwords and keys;
  • whom you connect and what you tell them about the server;
  • following the laws of the country where the server stands and of the countries of your clients, the ones on keeping data about connections among them.

Updates

The server asks GitHub (api.github.com) for new versions by itself and downloads them from there (github.com, and ghcr.io images for Docker). The request carries nothing about your server or your clients. GitHub sees what any website sees: the address the request came from and the name of the program.

The other addresses the server reaches by itself are listed in “Privacy”.

Certificate

The menu gets a Let’s Encrypt certificate only with your consent, on the terms of Let’s Encrypt.

Changes to the terms

A new version of the terms shows once, on the first sign-in to the panel after an update. Who accepted the terms and when is kept in the database of your panel.
