Recipes

Ready-made scenarios: what to press in the panel and what to check. The server names, addresses and clients in the examples are made up.

  • Exit through another server An AmneziaWG channel to another server and a rule by countries and sites.
  • Channel group with a fallback Several channels under one name: by priority, round robin, per client.
  • Tunnel inside WebSocket For networks that let only web traffic through.
  • One subscription for several devices One subscription for all the devices of one person.
  • Reaching a device behind a client Reaching a client from the tunnel: from the server alone or from the whole network.
  • Routing on the client device Presets and geo sources for the AmneziaGeo app through a template.
  • Moving to another server A backup of the database and an installation on a new host from it.
