Пресеты маршрутизации Только в приложении AmneziaGeoПресеты получает только приложение AmneziaGeo, через шаблон клиента.Другие клиенты AmneziaWG этого не получают: им доходит только файл конфигурации.Подробнее

Пресет маршрутизации - список маршрутизации клиента AmneziaGeo, который хранится на панели и выдаётся приложению через hello интерфейса. Шаблон клиента называет пресеты, которые получают его клиенты; маршрутизация по ним идёт на устройстве, а не на сервере. Вкладка «Пресеты маршрутизации» страницы «Клиенты» перечисляет пресеты с временем изменения и числом шаблонов, которые их раздают; число ведёт в список шаблонов с выбранным пресетом.

Основное

«Имя» - до 64 знаков, одно на панель; так список зовётся на клиенте. «Включён по умолчанию» - клиент включает список, когда добавляет его, если у него не включён ни один другой список. «Только чтение» - клиент не даёт переименовать, править и удалить список и берёт новые версии пресета сам, без «Обновить»; включать и выключать список на устройстве можно.

Шаблоны

Часть «Шаблоны» называет шаблоны, которые раздают пресет, имя ведёт в настройки шаблона. Поле добавляет шаблон: в подсказке рядом с именем серым его нынешние пресеты, и пресет встаёт в шаблоне последним. Крестик снимает пресет с шаблона. Изменения сохраняются вместе с пресетом кнопкой «Сохранить»; копия пресета шаблонов не берёт.

Списки

Часть Что делает
Через VPN записи идут через туннель
Напрямую записи идут мимо туннеля
Блокировать клиент отбрасывает записи
Всё через VPN всё идёт через туннель, кроме того, что идёт напрямую
Весь UDP через туннель каждый UDP-пакет идёт через туннель, что бы ни говорили списки: для звонков и игр, которые узнают адреса не через DNS

Записи пишутся так же, как в шаблоне: geoip:ru, geosite:youtube, cidr:10.0.0.0/8, domain:example.com, до 256 в каждой части. «Через VPN» и «Напрямую» берут ещё программы: app:<имя>, например app:Telegram, - приложение клиента само находит программу на устройстве (на Windows - по установленным программам, ярлыкам меню «Пуск» и App Paths, на Linux - по ярлыкам .desktop и PATH, на Android - по подписи и пакету) и пропускает строку, если не нашло; прежние формы с видом - app:path=<путь>, app:dir=<папка>, app:name=<файл>, app:svc=<служба>, app:pkg=<пакет> - тоже. Поле показывает такие записи видом «Программа». Строка программы целиком остаётся одной записью, даже с пробелами; запятая делит её, только когда за ней идёт новая запись: app:Telegram, app:Zoom - две программы, app:Telegram, geoip:ru - программа и ключ гео. Программа может стоять и после другой записи: geoip:us, app:Discord Canary - ключ гео и программа. Hello отдаёт программы как есть, в AllowedIPs они не идут.

Все приложения через VPN

У пресета с флажком «Всё через VPN» в списке пресетов под именем стоит метка «Все приложения через VPN», у пресета с «Весь UDP через туннель» - «Весь UDP через VPN»; метка ведёт в форму. В форме над флажками стоит пояснение со ссылкой «Подробнее» сюда. Клиент поведёт через сервер все приложения устройства, кроме записей «Напрямую», или UDP всех приложений, даже если их адресов нет в списках. Через сервер пойдут и приложения, которым VPN не нужен: некоторые приложения могут заметить VPN, узнать адрес сервера или перестать работать. Такие приложения добавьте в «Напрямую». Клиент AmneziaGeo показывает у такого списка ту же метку, см. Все приложения через VPN на сайте клиента.

«Весь UDP через туннель» у нового пресета выключен.

Как приложение берёт пресет

У пресета есть постоянный идентификатор, который даётся при добавлении, и время последнего изменения списка: имени, записей и переключателей. Hello отдаёт их вместе со списком, и клиент знает список по идентификатору:

  • клиент без такого списка добавляет его и включает, если пресет включён по умолчанию, а клиент ни по какому списку не маршрутизирует;
  • клиент со списком оставляет своё; когда пресет новее, карточка списка на устройстве предлагает обновление, и хозяин устройства, приняв его, получает имя, записи и переключатели пресета вместо того, что держал список, а список остаётся включённым или выключенным, как был;
  • список пресета «Только чтение» берёт новую версию сам, как только клиент её получил, и правке на устройстве не поддаётся; флаг сняли - список снова обычный, а новая версия ждёт «Обновить»; флаг поставили снова - список, который на устройстве изменили, берёт пресет; пресет убрали из шаблона - список остаётся у клиента обычным;
  • список, который хозяин удалил, возвращается при следующем hello;
  • список, добавленный приложением старше идентификаторов под именем пресета, привязывается к пресету.

Карточка списка на устройстве показывает, откуда он: имя конфигурации клиента, то, которое даёт подписка. Вместе с пресетами hello отдаёт гео-источники панели: клиент добавляет источники, которых у него нет, по адресу и переводит источник с тем же именем и видом на адрес панели, чтобы ключи пресета называли списки, которые у клиента есть, см. Списки Geo. Сценарий целиком - Маршрутизация на устройстве клиента.

Удаление

Пресет, который называет шаблон, не удаляется: «Пресет раздаётся в шаблоне»; страница удаления называет эти шаблоны, сначала их снимают в части «Шаблоны». Клиенты, которые уже получили список, сохранят его.
