AmneziaGeo Server in Docker

The panel runs as a container from the image ghcr.io/bor-project/amneziageo-server in the network of the host: its tunnel interfaces, firewall rules and ports are the same as the service would have. The host keeps the amneziawg module, Docker with compose and the directories with the database and the settings; the panel itself, the utility, the WebSocket proxy and the console menu travel in the image. An update is a new image, a rollback is the previous tag.

Console menu

The console menu amneziageo-server: installation, updates and rollback, database backups, the address, port and path of the panel, users and tokens, the service and its log, certificates, the firewall, interfaces, WebSocket fronts, BBR and DNS for the clients.

Panel

  • Overview The state of the host, services, updates and backups.
  • Interfaces AmneziaWG server interfaces: addresses, ports, keys, obfuscation, WebSocket, firewall ports.
  • Clients Client configurations: the list, settings, export, traffic, disabling.
    • Templates What a client gets in its file: AllowedIPs from geo keys and domains, routing by name, DNS, MTU, keepalive.
    • Routing presets Routing lists for the AmneziaGeo client app.
  • Routing Where the traffic of the clients goes: rules, basic lists, channels, geo databases, DNS.
    • Rules Conditions and directions of traffic: through a channel, direct or blocked.
    • Basic Block and direct lists ahead of the rules.
    • Test Checking the route of a connection by name, port and client.
    • Channels Outbound connections through the host or a tunnel to another server, and their groups.
    • Geo lists Geo databases of countries and site categories for rules and templates.
    • DNS The DNS server for the clients: upstream servers, query channel, cache, interception, stand-in addresses.
  • Settings Server, certificates, subscriptions, users and roles, diagnostics.
    • Server Address, port, path and language of the panel, configuration name template, pre-releases.
    • Certificates The certificate of the panel: a Let's Encrypt domain or your own files.
    • Subscriptions Client configurations by link: port, path, certificate, update interval.
    • Users and roles Accounts, roles with permissions and tokens for scripts.
    • Diagnostics Component versions, the event log and the connection log.

Recipes

  • Exit through another server An AmneziaWG channel to another server and a rule by countries and sites.
  • Channel group with a fallback Several channels under one name: by priority, round robin, per client.
  • Tunnel inside WebSocket For networks that let only web traffic through.
  • One subscription for several devices One subscription for all the devices of one person.
  • Reaching a device behind a client Reaching a client from the tunnel: from the server alone or from the whole network.
  • Routing on the client device Presets and geo sources for the AmneziaGeo app through a template.
  • Moving to another server A backup of the database and an installation on a new host from it.

Utility

The utility: amneziageo-server <command> commands for the console and scripts, and the HTTP API for everything else.
