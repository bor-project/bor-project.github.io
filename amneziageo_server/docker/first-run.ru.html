Первый запуск

Если панель ставил amneziageo-server install, администратор, интерфейс и первый клиент уже есть, а в конце он напечатал адрес панели, логин и временный пароль: переходите к входу. Здесь тот же путь руками для панели, поставленной своим compose.yaml.

Первый администратор

cd /opt/amneziageo-docker
docker compose exec panel amneziageo-server init --user admin

Ключ --user в контейнере обязателен: учётные записи хоста в него не заходят.

Утилита спросит пароль дважды. С ключом --generate она придумает пароль сама и напечатает его один раз строкой password: .... Пароль выдаётся временным: при первом входе панель попросит заменить его; --permanent оставляет пароль как есть. init работает, только пока в панели нет включённого администратора; дальше учётные записи заводятся в панели или командой user add, см. Пользователи и роли.

Последней строкой утилита называет порт и путь панели.

Где отвечает панель

По умолчанию панель слушает только 127.0.0.1:8443 без TLS, в сети хоста её не видно. На первом старте она придумывает себе путь вида /<16 букв и цифр>/, чтобы вход нельзя было угадать, пишет его в журнал и в свою базу:

docker compose logs | grep "the panel answers"

Адрес, порт и путь панель берёт из server.env только до первого запуска: на первом старте она записывает их в базу и дальше читает оттуда, см. Сервер. Поставить панель в корень до первого старта - строка Web__Path=/ в server.env; потом путь меняет пункт 10 меню или вкладка «Сервер».

Открыть панель можно двумя способами.

  • Через SSH-туннель, без сертификата. На своём компьютере ssh -N -L 8443:127.0.0.1:8443 root@<адрес сервера>, в браузере http://localhost:8443/<путь>/.
  • В сети по TLS. Пункт 22 меню SSL Certificate Management выпускает сертификат Let’s Encrypt на имя сервера (имя должно указывать на хост, TCP 80 свободен) или берёт готовые файлы, ставит их панели и предлагает открыть её на всех адресах хоста; дальше панель отвечает на https://<имя>:8443/<путь>/. То же руками: вкладка Сертификаты, затем Сервер > «Слушать на адресах» > «Все адреса»; или строки Web__Listen__0=*:8443, Web__Certificate и Web__CertificateKey в server.env до первого старта.

Порт панели в брандмауэре хоста открывает пункт 23 меню или кнопка «Открыть» под полем порта на вкладке «Сервер», см. Порты в брандмауэре.

Вход

Страница входа спрашивает имя и пароль; над формой стоят переключатели темы и языка, чтобы браузер без русского и английского не остался ни с чем. Временный пароль панель просит заменить сразу: «Пароль выдан администратором, замените его». Десять промахов закрывают вход на пятнадцать минут. Что видно после входа - Панель.

Первый интерфейс

«Интерфейсы» > «Добавить». Панель предлагает заготовку, которая уже сходится: имя awg0, UDP-порт 51820 или первый свободный выше, сеть 10.8.0.1/24, MTU 1420, keepalive 25, DNS 1.1.1.1 и 1.0.0.1, новая пара ключей и случайная обфускация. Проверьте четыре вещи.

  1. Хост - адрес или имя, по которому клиенты найдут сервер; он идёт в строку Endpoint файлов клиентов. Панель подставляет имя другого интерфейса, домен сертификата панели или публичный IPv4 хоста, если знает их; без хоста включённый интерфейс не сохранится.
  2. NAT для клиентов - включён, чтобы клиенты выходили в интернет под адресом хоста.
  3. Порт и Порт сервисов - если брандмауэр хоста закрывает их, форма говорит это под полем и предлагает «Открыть при сохранении».
  4. WebSocket прокси - по желанию, для сетей, где проходит только веб-трафик; если прокси не запустится, панель снимет отметку и назовёт причину.

«Сохранить» кладёт интерфейс в ядро. Поля подробно - Интерфейсы.

Первый клиент

«Клиенты» > «Добавить»: имя, интерфейс, адрес из сети интерфейса (первый свободный уже подставлен), ключи сгенерированы. После «Сохранить» клиент открывается на вкладке «Экспорт»: файл .conf, ссылка vpn:// и адрес подписки, каждый QR-кодом, с копированием и скачиванием. Подробно - Клиенты.

На устройстве конфигурацию принимает клиент AmneziaGeo для Windows, Linux и Android, он описан на своём сайте, или любое другое приложение AmneziaWG. Одна конфигурация - одно устройство: два устройства с одним ключом отбирают сессию друг у друга, каждому человеку на каждое устройство заводится свой клиент.

DNS для клиентов

Свежая панель держит резолвер выключенным: клиенты получают в конфигурации серверы имён и спрашивают их через туннель открытым DNS. Пункт 29 меню DNS for Clients, команда amneziageo-server dns on или отметка «Отвечать клиентам» на странице DNS включают резолвер панели: клиенты спрашивают имена у сервера, сервер спрашивает внешние серверы по HTTPS, и правила маршрутизации по доменам начинают работать.

Проверка

docker compose ps показывает контейнер healthy; amneziageo-server status (пункт 18 меню) печатает службу, ответ панели и версию, модуль, пересылку и строку служб. В панели карточка «Службы» на Обзоре перечисляет подписки, каждый интерфейс, резолвер и сертификаты с тем, что мешает им работать. Интерфейс на хосте: ip -d link show type amneziawg и amneziageo-server device list.
